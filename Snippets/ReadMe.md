# راهنمای استفاده از اسنیپت‌های CSS در Nora HTML Exporter

این راهنما توضیح می‌دهد چطور با استفاده از فایل‌های CSS، ظاهر کتاب یا یادداشت خروجی‌گرفته‌شده از **Nora HTML Exporter** را شخصی‌سازی کنید؛ بدون اینکه فایل اصلی یادداشت Markdown تغییر کند.

> اسنیپت‌های این بخش، کدهای CSS برای تغییر ظاهر خروجی نورا هستند؛ نه اسنیپت‌های متنی یا کدهای اجرایی Obsidian.

## اسنیپت CSS چیست؟

CSS زبانی برای تعیین ظاهر عناصر یک صفحه است؛ مثلاً رنگ عنوان‌ها، فاصلهٔ پاراگراف‌ها، پس‌زمینهٔ نقل‌قول‌ها یا ظاهر جدول‌ها.

در نورا می‌توانید یک فایل CSS را انتخاب کنید تا قواعد آن در انتهای استایل کتاب‌خوان HTML قرار بگیرد. در نتیجه، قواعد شما می‌توانند ظاهر پیش‌فرض نورا را تغییر دهند یا بازنویسی کنند.

این تغییرات مربوط به **خروجی HTML نورا** هستند و محتوای فایل Markdown در Vault را ویرایش نمی‌کنند.

## روش اول: ساخت فایل CSS در پوشه snippets

### ۱. پیدا کردن پوشهٔ snippets

در Vault خود به پوشهٔ تنظیمات Obsidian بروید:

```text
<Vault>/.obsidian/snippets/
```

اگر پوشهٔ `snippets` وجود ندارد، آن را داخل پوشهٔ `.obsidian` بسازید.

در macOS و Linux مسیر معمولاً به همین شکل است. در ویندوز نیز مسیر همین ساختار را دارد؛ فقط جداکنندهٔ مسیر ممکن است `\\` باشد.

### ۲. ساخت فایل

داخل پوشهٔ `snippets` یک فایل متنی با پسوند `.css` بسازید. برای مثال:

```text
.obsidian/
└── snippets/
    └── nora-reading-style.css
```

فایل را با یک ویرایشگر متن باز کنید و قواعد CSS خود را داخل آن بنویسید.

### ۳. ذخیره کردن

پس از نوشتن کد، فایل را ذخیره کنید. برای استفاده از آن در نورا لازم نیست کد را در یادداشت Markdown قرار دهید.

## نام‌گذاری فایل

نورا در فهرست انتخاب اسنیپت‌ها فقط فایل‌های CSS را نمایش می‌دهد که نام فایل آن‌ها با `nora` شروع شود؛ حروف بزرگ و کوچک در این بررسی تفاوتی ندارند.

نمونه‌های قابل شناسایی:

- `nora-sepia.css`
- `nora-minimal.css`
- `Nora-Headings.css`

نمونه‌هایی که در فهرست نورا نمایش داده نمی‌شوند:

- `sepia.css`
- `my-style.css`
- `nora-style.txt`

برای اطمینان، فایل را مستقیماً داخل پوشهٔ `.obsidian/snippets` قرار دهید و از قرار دادن آن در زیرپوشه‌ها خودداری کنید.

## انتخاب اسنیپت در تنظیمات نورا

1. در Obsidian وارد **Settings** شوید.
2. بخش **Nora HTML Exporter** را باز کنید.
3. گزینهٔ **Select CSS Snippet from Vault (optional)** را پیدا کنید.
4. از فهرست، فایل CSS موردنظر را انتخاب کنید.
5. برای تازه‌سازی فهرست فایل‌ها، دکمهٔ تازه‌سازی کنار این گزینه را بزنید.

اگر گزینهٔ **None (Disabled)** انتخاب شود، فایل CSS انتخاب‌شده استفاده نمی‌شود.

پس از انتخاب فایل، نورا تنظیمات را ذخیره می‌کند و پیش‌نمایش‌های باز را تازه‌سازی می‌کند. هنگام خروجی گرفتن، قواعد فایل انتخاب‌شده در HTML قرار می‌گیرند.

## روش دوم: نوشتن CSS در خود تنظیمات

اگر فقط چند قاعدهٔ کوتاه دارید یا نمی‌خواهید فایل جداگانه بسازید:

1. به **Settings → Nora HTML Exporter** بروید.
2. گزینهٔ **Custom CSS** را پیدا کنید.
3. کد CSS را در کادر وارد کنید.
4. تنظیمات را ذخیره کنید.

این کادر برای قواعدی است که می‌خواهید مستقیماً به خروجی اضافه شوند. CSS نوشته‌شده در این قسمت در انتهای استایل خروجی قرار می‌گیرد و می‌تواند استایل پیش‌فرض و فایل CSS انتخاب‌شده را بازنویسی کند.

**ترتیب اثرگذاری:** استایل پیش‌فرض نورا ← فایل CSS انتخاب‌شده ← کد داخل کادر Custom CSS.

## نمونه‌های آماده CSS

می‌توانید هر نمونه را به‌تنهایی در فایل CSS قرار دهید یا چند نمونه را با هم ترکیب کنید.

### تغییر رنگ عنوان اصلی

```css
.article h1 {
  color: #8b4513;
  border-bottom-color: #d6b98c;
}
```

### خواناتر کردن پاراگراف‌ها

```css
.article p {
  line-height: 1.9;
  text-align: justify;
}
```

### تغییر ظاهر عنوان‌های سطح دوم

```css
.article h2 {
  color: #477a68;
  border-inline-start-color: #477a68;
}
```

### ساده‌تر کردن نقل‌قول‌ها

```css
.article blockquote {
  border-radius: 6px;
  box-shadow: none;
  background: rgba(120, 140, 120, 0.08);
}
```

### تغییر ظاهر لینک‌ها

```css
.article a {
  text-decoration: underline;
  border-bottom: none;
}
```

### تغییر ظاهر جدول‌ها

```css
.article table {
  border-radius: 6px;
  font-size: 0.95em;
}

.article th {
  text-align: start;
}
```

### تغییر ظاهر کدهای درون‌خطی

```css
.article code {
  border-radius: 4px;
  padding: 0.15em 0.4em;
}
```

### تنظیم گوشه‌های تصاویر

```css
.article img {
  border-radius: 8px;
}
```

### یک نمونهٔ ترکیبی

این نمونه را می‌توانید به‌عنوان محتوای اولیهٔ فایل `nora-custom.css` استفاده کنید:

```css
/* عنوان‌ها */
.article h1 {
  color: #8b4513;
  border-bottom-color: #d6b98c;
}

.article h2 {
  color: #477a68;
  border-inline-start-color: #477a68;
}

/* متن */
.article p {
  line-height: 1.9;
  text-align: justify;
}

/* نقل‌قول */
.article blockquote {
  border-radius: 6px;
  background: rgba(120, 140, 120, 0.08);
}

/* تصاویر */
.article img {
  border-radius: 8px;
}
```

## چطور CSS را تغییر دهیم؟

برای تغییر ظاهر، مقدارهای داخل قواعد را ویرایش کنید. چند مورد پرکاربرد:

| ویژگی | کاربرد | نمونه |
|---|---|---|
| `color` | رنگ متن | `color: #477a68;` |
| `background` | پس‌زمینه | `background: #f5f0e6;` |
| `font-size` | اندازهٔ متن | `font-size: 1.1em;` |
| `line-height` | فاصلهٔ خطوط | `line-height: 1.9;` |
| `border-radius` | گردی گوشه‌ها | `border-radius: 8px;` |
| `margin` | فاصلهٔ بیرونی | `margin: 1em 0;` |
| `padding` | فاصلهٔ داخلی | `padding: 12px;` |

برای رنگ‌ها می‌توانید از کدهای HEX مانند `#477a68` یا مقدارهای `rgb()` و `rgba()` استفاده کنید.

## رفع اشکال

### فایل در فهرست نورا دیده نمی‌شود

- مطمئن شوید پسوند فایل `.css` است.
- نام فایل باید با `nora` شروع شود؛ مانند `nora-sepia.css`.
- فایل را در پوشهٔ `.obsidian/snippets` قرار دهید.
- دکمهٔ تازه‌سازی کنار فهرست اسنیپت‌ها را بزنید.
- بررسی کنید فایل واقعاً ذخیره شده و خالی نیست.

### CSS انتخاب شده، اما ظاهر تغییر نکرده است

- مطمئن شوید گزینهٔ **None (Disabled)** انتخاب نشده باشد.
- نام کلاس و عنصر را درست نوشته باشید؛ برای محتوای یادداشت، از انتخابگرهایی مانند `.article p` و `.article h1` استفاده کنید.
- بعد از تغییر CSS، پیش‌نمایش را تازه‌سازی کنید یا خروجی HTML را دوباره بگیرید.
- اگر قاعده‌ای با استایل پیش‌فرض تداخل دارد، انتخابگر دقیق‌تری بنویسید. استفاده از `!important` را فقط در صورت ضرورت امتحان کنید.

### تغییر در فایل HTML قبلی دیده نمی‌شود

استایل هنگام ساخت خروجی HTML در فایل قرار می‌گیرد. پس از تغییر CSS، فایل HTML قبلی را دوباره خروجی بگیرید تا تغییرات در نسخهٔ جدید اعمال شوند.

## نکته‌های مهم

- CSS فقط ظاهر را تغییر می‌دهد؛ متن یادداشت را اصلاح یا بازنویسی نمی‌کند.
- کد CSS را داخل بلوک Markdown یا کد JavaScript قرار ندهید؛ آن را در فایل `.css` یا کادر **Custom CSS** وارد کنید.
- قواعدی که با `.article` شروع می‌شوند روی محتوای اصلی یادداشت و فصل‌ها اعمال می‌شوند.
- برای برگشت به ظاهر پیش‌فرض، اسنیپت را از فهرست انتخاب نکنید یا گزینهٔ **None (Disabled)** را انتخاب کنید؛ همچنین می‌توانید محتوای کادر **Custom CSS** را پاک کنید.
- در این پوشه، هر فایل CSS باید با نام `nora` شروع شود تا در انتخابگر نورا قابل شناسایی باشد.
